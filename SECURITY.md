# Security Policy

Do not open public issues for suspected vulnerabilities, leaked credentials, or exploitable deployment mistakes.

Report security issues privately to Laurent Bindschaedler at laurent@bindschaedler.com. Include the affected component, reproduction steps, expected impact, and any relevant logs or transaction hashes. Do not include private keys or live credentials.

This repository is a research prototype. The pinned Base Sepolia deployment is historical, differs from current source, and uses a mock ERC-792 arbitrator. Do not send funds or claims to it.
