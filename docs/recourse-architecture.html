Business context

Objective

Measure bounded residual harm after risky autonomous actions and test whether a bonded claim path can compensate it.

Actors

Operator, agent runtime, claimant, challenger, adapter/compensator signers, and settlement contracts.

Primary metrics

Gross harm, recovered harm, bonded coverage, uncompensated loss, routing correctness, latency, gas, and collateral shortfall.

Processing pipeline

1. Admission

Evaluate κ and explicit, independently verified observations. Missing facts fail closed.

2. Side effect

Validate commit-path configuration, execute the tool call, then issue a typed receipt.

3. Recovery

Attempt compensation and issue a recovery receipt bound to the effect digest.

4. Classification

Route objective L0 facts optimistically; route L1/L2 or disputed facts to arbitration.

5. Claim

Commit receipt/evidence hashes, submit a claimant-signed capped amount, and reserve exposure.

6. Finalization

Resolve the local mock optimistic/arbitrated path and release or slash reserved collateral.

System architecture

Runtime layer

  • TypeScript receipts, adapters, compensators, and evidence store
  • Python eligibility, settleability, routing, and evaluation harness
  • JSON schemas plus cross-language hashing fixtures

Contract layer

  • RecourseRegistry and BondVault
  • ClaimRegistry lifecycle and exposure reservation
  • OptimisticPath plus ArbitrablePath

Features and non-goals

Implemented and tested

Canonical hashing, typed local signatures, fail-closed classifier inputs, deterministic synthetic sweeps, local provider-compatible integrations, and local-chain settlement tests.

Not established by this artifact

Managed-provider attestations, public-state receipt replay, operator-independent receipt commitment, on-chain payout formula evaluation, or production-ready live UMA/Kleros settlement.

Deployment and reproduction

Toolchain

Foundry 1.3.5, Bun 1.3.5, uv 0.11.28, Python 3.12, and digest-pinned integration images.

Local services

Docker Compose starts Postgres and LocalStack. Git uses a temporary bare repository.

Outputs

Fresh result roots carry configs, realized seeds, dirty state, tool versions, checksums, tables, figures, and claim-validation status.
